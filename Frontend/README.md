# OficiosYa — Frontend

Next.js 16 (App Router) + PWA.

## Scripts

| Comando | Descripción |
|---|---|
| `pnpm dev` | http://localhost:3000 |
| `pnpm build` / `pnpm start` | Producción |
| `pnpm test:e2e` | Playwright (API + web locales + seed) |
| `pnpm lint` / `typecheck` / `test` | Calidad |

Deploy: Vercel — Root Directory `Frontend` (`vercel.json`).
